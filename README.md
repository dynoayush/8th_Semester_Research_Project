# Medi-Link — Intelligent Healthcare Consultation System

An AI-powered Disease Prediction & Medical RAG Chatbot using **XGBoost**, **FAISS**, and **Llama 3 (Groq)** with a **Streamlit** interface.

## Features

| Module | Description |
|---|---|
| **RAG Chatbot** | Describe your symptoms in natural language → get AI-powered medical insights grounded in the MedQuAD dataset |
| **ML Symptom Predictor** | Select symptoms from a list → XGBoost model predicts the most likely disease |
| **Medicine Recommender** | Enter a disease name → get medications, diet, workout, and precaution recommendations |

## Setup & Installation (Step by Step)

### Step 1: Clone the Repository

```bash
git clone https://github.com/dynoayush/8th_Semester_Reearch_Project.git
cd 8th_Semester_Reearch_Project
```

### Step 2: Create a Virtual Environment (Recommended)

```bash
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # macOS/Linux
```

### Step 3: Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 4: Create the `.env` File

Create a file named `.env` in the project root directory with the following content:

```env
LANGCHAIN_API_KEY="your_langchain_api_key_here"
LANGCHAIN_PROJECT="GenAIAppWithOpenAI"
HF_TOKEN="your_huggingface_token_here"
GROQ_API_KEY="your_groq_api_key_here"
```

**Where to get these keys:**

| Key | Get it from |
|---|---|
| `GROQ_API_KEY` | [console.groq.com/keys](https://console.groq.com/keys) — Sign up for free, create an API key |
| `HF_TOKEN` | [huggingface.co/settings/tokens](https://huggingface.co/settings/tokens) — Create a read token |
| `LANGCHAIN_API_KEY` | [smith.langchain.com/settings](https://smith.langchain.com/settings) — Create an API key (optional, for tracing) |

> **Never commit your `.env` file to GitHub!** It is already listed in `.gitignore`.

### Step 5: Download the Datasets

Since the CSV and large dataset files are not included in the repository, you need to download them manually:

#### 5a. MedQuAD Dataset (for RAG Chatbot)

```bash
git clone https://github.com/abachaa/MedQuAD.git MedQuAD-master
```

This creates the `MedQuAD-master/` folder with all the medical Q&A XML files.

#### 5b. Disease & Symptoms Dataset

Download the **SympScan — Symptoms to Disease** dataset from Kaggle:

🔗 [https://www.kaggle.com/datasets/behzadhassan/sympscan-symptomps-to-disease](https://www.kaggle.com/datasets/behzadhassan/sympscan-symptomps-to-disease)

After downloading, place all CSV files in a folder called `Data_Required/`:

```
Data_Required/
├── Diseases_and_Symptoms_dataset.csv
├── description.csv
├── medications.csv
├── diets.csv
├── precautions.csv
└── workout.csv
```

### Step 6: Build the FAISS Vector Index

Open and run all cells in **`code.ipynb`**. This will:
- Parse the MedQuAD XML files
- Create embeddings using `sentence-transformers/all-MiniLM-L6-v2`
- Build and save the FAISS index to `medquad_index/`

### Step 7: Train the XGBoost Model

```bash
python setup_models.py
```

This will generate:
- `xgb_model.pkl` — Trained XGBoost classifier
- `label_encoder.pkl` — Label encoder for disease names
- `symptoms_list.pkl` — List of symptom features

### Step 8: Run the Application 🎉

```bash
streamlit run app.py
```

The app will open in your browser at `http://localhost:8501`

## RAG Evaluation

Run the evaluation script to benchmark the RAG chatbot:

```bash
python evaluate_rag.py
```

This uses a separate **Qwen 32B** model as a judge to score the chatbot's responses on:
- **Faithfulness** (0–50): Is the answer grounded in the retrieved context?
- **Answer Relevance** (0–50): Does the answer address the question?

Results are saved to `rag_evaluation_results.csv`.
